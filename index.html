Chapter 2: How I make games

Chapter 2

How I make games

Every idea starts as a feeling I want the player to have. Then I follow the same four steps, and I let the numbers keep me honest.

  1. Concept

    Start from a player feeling, then write the loop that creates it.

  2. Prototype

    Code it fast so the idea can be played this week.

  3. Test with data

    Run AI-assisted testing and read the numbers, not just opinions.

  4. Balance

    Adjust until the game is fair, tense and worth replaying.
